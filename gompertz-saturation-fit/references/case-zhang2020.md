# 案例一：张安迎等（2020）中国报废汽车铂族金属回收潜力估算

参考实现，用于核对参数与写法。原文：《中国环境科学》2020, 40(11): 4821-4830，
DOI 10.19674/j.cnki.issn1000-6923.2020.0534。

## 1. 论文的 Gompertz 用法

**自变量**：人均 GDP（万元/人）；**因变量**：人均汽车保有率（辆/人）。
数据：《中国统计年鉴》1996–2017 年人均 GDP 与人口，《中国汽车工业年鉴》民用汽车拥有量。

模型：`v = γ · exp(α · exp(β · x))`，用 SPSS 非线性回归拟合。

**表1（γ 自由）**

| 参数 | 估计值 | 95% CI 下限 | 95% CI 上限 |
|---|---|---|---|
| γ | 0.464 | 0.334 | 0.593 |
| α | −4.211 | −4.397 | −4.025 |
| β | −0.224 | −0.258 | −0.190 |
| R² | 0.998 | | |

**表2（固定 γ = 0.62，OECD 通用餍足点）**

| 参数 | 估计值 | 95% CI 下限 | 95% CI 上限 |
|---|---|---|---|
| α | −4.394 | −4.491 | −4.297 |
| β | −0.194 | −0.199 | −0.189 |
| R² | 0.998 | | |

结论：2000 年以前两模型拟合都较差，2001 年以来预测误差均在 5% 以内；
考虑人口密度与城市化水平，最终采纳自由 γ = 0.464。

**外推路径**：先用 SPSS 的 Brown 线性趋势外推 2018–2050 年的人口与人均 GDP
（人口 R²=0.999、RMSE=57.9；人均 GDP R²=0.997、RMSE=0.098；Holt 模型与 Brown
几乎相同，见表3），再代入 Gompertz 得保有量。

**结果**：2020 年人均保有量 0.21 辆/人（加速增长期结束），2050 年 0.45 辆/人，
2050 年后收敛于餍足点 0.46 辆/人；社会保有量 2020 年 29505 万辆、
2025 年 42696 万辆、2050 年 73758 万辆。

## 3. 论文的下游链条（超出本 skill 范围，但复现时需要）

1. **理论报废量**（式3）：`Q_t = I_t − ΔH_t`，I_t = 销售 + 进口 − 出口；
   ΔH_t = H_t − H_{t−1}。民用汽车口径代替社会保有量会让 ΔH 偏小、报废量偏大。
2. **报废高峰年限**：新增量曲线与报废量曲线对比，1996 年新增量 ≈ 2005 年报废量，
   推出报废高峰约 9 a。
3. **市场供给 A 模型**（式4）：`Q_t = Σ_{i=1}^{n} S_{t−i} · P_i`，
   废弃率 P_i 用 Weibull 寿命分布（式5-8）算。
4. **Weibull 参数**：由平均寿命 T_average=9 a、最长寿命 T_max=15 a 反解
   `η = T_max · ((−ln 0.01)^(1/β) − 1)^(1/β)`、`T_average = η · Γ(1+1/β)`，
   得 β=3.623（负偏态）、η=9.839。
5. **空间分布**：各省人均 GDP 代入 Gompertz → 人均保有率 → 归一化为权重 → 分配全国报废量。
6. **物质流分析**（式9）：回收潜力 `R_t = Σ_{i=t−15}^{t−1} Q_{t,i} · p_i`，
   p_i 为第 i 年单位汽车铂族金属用量（由庄信万丰需求量 ÷ 国内汽车产量得到）。
7. **情景1/2**：情景1 = 维持 2018 年单位用量（Pt/Pd/Rh 0.16/2.33/0.28 g/辆）；
   情景2 = 2020 年起对标 Euro 6d（3.01/3.88/0.30 g/辆）。

## 4. 论文自己承认的局限（写自己的论文时值得抄）

- 用民用汽车拥有量代替社会保有量 → ΔH 偏小 → 报废量偏大
- 催化剂在车辆寿命内可能更换（更换率 5%~8% 未计入）→ 低估回收潜力
- 新能源汽车保有量（2019 年 381 万辆，占 1.19%）需按 1%~2% 剔除
- 情景2 用欧洲单位用量可能高估：欧洲柴油车多、铂用量高，我国以汽油车为主、单钯催化剂为主
