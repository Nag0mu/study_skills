# Gompertz 模型：数学、估计与判读

## 1. 模型形式与参数含义

论文（张安迎等 2020，《中国环境科学》40(11):4821-4830）使用的形式：

```
v = γ · exp( α · exp( β · x ) )
```

| 符号 | 含义 | 本 skill 内部形式 |
|---|---|---|
| v | 人均保有率（辆/人） | y |
| x | 人均 GDP（万元/人） | x |
| γ | 餍足点/饱和上限 | A |
| α | 负值，刻画拐点位置与上升曲率 | −B |
| β | 负值，刻画 S 型陡峭程度 | −k |

等价正参数形式（数值更稳，脚本内部使用）：

```
y = A · exp( −B · exp( −k · x ) ),  A>0, B>0, k>0
```

- **γ = A**：市场趋于饱和时的人均保有量上限
- **α = −B**：决定曲线在多高的 x 处开始减速
- **β = −k**：S 型的陡峭程度；k 越大，过渡越快

换算：γ 固定时 `alpha = -B`、`beta = -k`；脚本报告里 `alpha` 一列在 x 为年份量级时会显示为
"(shifted)"，因为原尺度下的 α 数值溢出，见 §3。

拐点（增速最大的位置）：

```
x* = ln(B / k) / k        y(x*) = A · exp(−B / e)
```

## 2. 为什么不能直接丢给最小二乘

Gompertz 对 (A, B, k) 是非线性的，且**三个参数高度相关**：只要数据没越过拐点，
"A 更大"和"B 更大"可以互相补偿，SSE 曲面是一条峡谷。直接用 `scipy.optimize.least_squares`
从默认初值出发，很容易停在退化解上（k→0 或 A→∞）。

脚本采用**剖面法（profile）+ 精修**两步：

1. **剖面**：固定饱和值 A，对每个候选 A 做变换 OLS

   ```
   ln( ln(A / y) ) = ln(B) − k·x      →  对 x 做线性回归，得 B、k
   ```

   在 log 网格上扫 A（默认 250 个点，从 max(y) 到 1000×max(y)），取 log 空间 SSE 最小者。
   这一步保证不会掉进局部极小。

2. **精修**：用 `least_squares`（trf，带边界）在这个初值上做有界最小二乘，
   得到在原始 SSE 意义下最优的 (A, B, k)，并由解析 Jacobian 求协方差。

对**固定 γ**（情景假设）的情况，变换 OLS 直接给出 B、k 的闭式解，再做同样的精修。

## 3. 必须做的 x 平移（数值陷阱）

若 x 是年份（值约 2010）且 k≈0.1~0.2，则 `exp(−k·x) ≈ exp(−400)`，已经下溢到 0，
曲线在数值上变成一条水平线，梯度消失，B 与 k 无法区分，拟合必然失败或给出垃圾参数。

脚本内部统一令 `x_ref = min(x)`，用 `x' = x − x_ref` 拟合，最后把结果换算回原尺度：

```
B_orig = B' · exp(k · x_ref)      （A、k 不变）
```

- γ 和 β 与平移无关（β = −k 在任何平移下不变）
- α（= −B）依赖平移；x 为年份量级时 `exp(k·x_ref)` 会溢出，此时报告"shifted"形式
  并写明 `x' = x − x_ref`，不要在论文里写一个 1e122 的 α。

## 4. 可识别性：饱和点是不是数据给的？

如果拐点 `x*` 落在观测 x 范围之外，说明数据只走完了 S 型的加速段，
**饱和值 γ 是外推出来的，不是数据识别出来的**。此时：

- 自由 γ 的置信区间通常会横跨一个数量级以上（脚本会报警告）
- 论文的做法是把它当作**情景假设**来对比：自由 γ=0.464（表1） vs 固定 γ=0.62
  （OECD 通用餍足点，表2），两者 R² 都是 0.998，最终采纳更贴合自身人口密度/
  城市化水平的自由解

脚本的对应能力：`--gamma 0.62 --gamma 0.45 ...` 可同时跑多个固定 γ 情景，
`parameters.csv` 里逐情景给出 R²/RMSE/MAPE/AIC/拐点，便于直接做成论文里的对比表。

选 γ 的三条经验规则：

1. 有外部基准（OECD 0.62、文献 0.3~0.45/0.4~0.7）且自由解与之接近 → 用自由解，报告基准值作为稳健性检验
2. 自由解的 CI 极宽 → 用外部基准固定 γ，并把 γ 作为情景做敏感性分析
3. 不同 γ 情景导致结论反转 → 结论必须写成"在 γ=X 情景下"，不能给单一数字

## 5. 不确定度

- **95% CI**：由解析 Jacobian 求协方阵 `cov = pinv(JᵀJ)·s²`，再用 t 分布临界值。
  这是渐近区间，不含模型选择、缺失值、外生变量外推带来的不确定性。
- **Bootstrap**：`--bootstrap 200` 用残差重抽样，给出更稳健的区间
  （尤其在同方差被违反时）。
- **预测带**：`predictions.csv` 的 `y_lower95/y_upper95` 是由参数协方差做 2000 次
  蒙特卡洛抽样得到的 2.5%/97.5% 分位。论文里画预测区间时可以直接用。

## 6. 模型选择与验证

- **基准模型**：`--compare-logistic` 同时拟合 Logistic（`y = A/(1+exp(−k(x−x0)))`），
  用 AIC 比较。两者 R² 几乎一样时（常见于拐点附近数据），优先看 AIC 与外推行为。
- **留出验证**：`--backtest` 做**按时间顺序**的分折验证（用过去预测未来），
  而不是随机抽折——随机抽折会用到"未来信息"，对增长曲线无效。
  论文表 4 的逐年预测误差本质上就是这种检验。
- **报告误差表**：像论文那样给出每个观测年的预测误差 %（或至少在图上标出），
  比只给 R² 有说服力得多。

## 7. x 的选择与单位

- 论文用 **人均 GDP** 作自变量，而不是年份。好处是能跨省/跨国比较，也能解释机制；
  代价是必须先外推 GDP 与人口（论文用 SPSS 的 Brown 线性趋势外推 2018~2050）。
- **单位会改变 β**。x 用"万元/人"还是"元/人"，同一模型 β 相差 100 倍。
  论文用万元/人；脚本不替你选单位，报告里必须写清 x 的单位。
- 用**当年价美元**做 x 时要小心汇率噪声（挪威 2015 年 GDP 美元值跳水而车辆仍在增长）。
  换成不变价或 PPP 口径更稳。
- 若 x 是年份，注意模型描述的是"存量随时间的饱和"，此时 γ 解释为最终保有量，
  外推只在"没有新冲击"的前提下成立（电动化会打破这条曲线，挪威 2021 年后已见平台期）。

## 8. 空间分配权重（论文的加权分配法）

论文第 1.2 节用 Gompertz 拟合出各省人均保有率，再**归一化成权重**，
把全国报废量按权重分配到各省：

```
weight_i = v_i / Σ_j v_j          （v_i 为各省用同一模型算出的预测人均保有率）
```

脚本对应 `--weight-col <省份列>`：对每个地区取其最新 x 值，用拟合模型算出 v_i，
归一化后写入 `spatial_weights.csv`；加 `--allocate <全国总量>` 可直接输出分配量。
注意这是**份额分配**，不是独立模型：它假设各省相对关系稳定，且总量本身可靠。

## 9. 与下游链条的衔接（论文全流程）

Gompertz 只负责"保有量"这一环，论文的完整链条是：

```
人均GDP/人口外推(Brown/Holt) → Gompertz 保有量 → 保有量变化 + 新增量 → 理论报废量
   → Weibull 寿命分布(平均寿命9a、最长15a) + 市场供给A模型 → 报废量时空分布
   → 物质流分析(MFA) → 铂族金属回收潜力与需求 → 情景1/2 供需对比
```

若要做报废量预测，可复用本 skill 的 `city-vehicle-panel-completion`
（城市-年份面板补全）与 Weibull 寿命设定，但不要把 Gompertz 当成报废量模型：
报废量是保有量的一阶差分，噪声会被放大。

## 10. 常见坑清单

1. x 是年份却没做平移 → 拟合失败或参数荒谬（本脚本已内置平移）
2. 只报告 R² 不报告 γ 的 CI 与拐点位置 → 无法判断饱和是否被数据识别
3. 把外推值当成观测值使用 → 必须在图/表上区分
4. 固定 γ 情景选得比自由解好，就直接用固定值 → 应同时报告，解释选择依据
5. 用当年价美元 GDP 做 x，汇率波动被误读成饱和迹象
6. 对 y 直接做 OLS 而非线性最小二乘，或反之（在 log 尺度拟合但用自然尺度报 RMSE）→ 指标与模型不一致
7. 数据点少于 5 个、或 y 存在 0/负值 → 脚本会直接报错，不要强行拟合
8. 把 Gompertz 外推用于"结构会变"的场景（新能源渗透、共享出行、政策补贴退坡）
